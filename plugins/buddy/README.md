# buddy

A tiny companion that walks on your Claude Code prompt line and talks back: Quack the duck by default, six more characters built in (`professor`, `cat`, `robot`, `ghost`, `dragon`, `yellow-duck`), or your own.

```text
/buddy                  open or fold the drawer: the buddy, its thread with you, its personalities
/buddy off | on         hide or show it, remembered and shared by your sessions
/buddy reload           rescan the characters after you edit one
/buddy help             usage, and any option ignored or capped
/buddy log              the log file's path and its last 20 lines, for an issue
/buddy list | use {id}  moved: replies pointing to the drawer's personality tab, no model call
/buddy {question}       a one-line answer, in character
```

It reacts to the work: a failed tool call, a test runner's run passing or failing. A question is one fast call on `model` (default `opus`; `inherit` follows the main chat's model) at the `effort` option's level (default `low`; `inherit` uses the effort of the main chat's latest request, none before its first, so the model's default applies), seeing its `chatTurnsToRead`, its short-term memory (the chat's last turns, default 4, 1 to 10, a compaction counting as one with its summary, each prompt kept to its first 4,800 and last 2,400 characters and each answer to its first 8,000 and last 3,200, each with what it said after it and your /buddy questions with its answers, kept whole; it knows it remembers no further, and says so when asked about anything older), and told to become the character completely and say one useful thing that both you and Claude missed; the options `commentAfterEachTurn`, `model`, `effort`, `secondsBetweenComments` and `suggestNextPrompt` decide what spends tokens; `commentAfterEachTurn` and `suggestNextPrompt` (both on by default) let one short call at the end of every answered turn write `commentAfterEachTurn` and `suggestNextPrompt` (a `model` call on its `chatTurnsToRead`, about 3 seconds), Claude Code's own suggestion held back and shown only when the buddy has none (`commentAfterEachTurn: false` or `suggestNextPrompt: false` turns either off, and `secondsBetweenComments`, default 0, spaces `commentAfterEachTurn` out); the `commentAfterEachTurn` and `suggestNextPrompt` a turn showed are remembered together under that turn, so it can say what it suggested last, per session and per character. A question is answered at once, even while the main chat is busy mid-turn. One question is answered at a time (asking again meanwhile gets `still thinking about your last question`), and every question ends in the bubble: an answer, which holds it for 15 seconds, or `{name} couldn't answer: {reason}`, such as `no answer in 90 s`, a question's deadline; an answer that arrives after a switch to another character is dropped. `logLevel` (error, info, debug; default info) and `logFile` (default `~/.claude/buddy/buddy.log`, or `$CLAUDE_CONFIG_DIR/buddy/buddy.log` when that is set; a path you set is used with `~` and a leading `$CLAUDE_CONFIG_DIR` expanded; empty = none; one JSON line per record, retried when another session writes at the same moment, 1 MB with one rotation) set the plugin log, which `/buddy log` shows; each question's `ask.outcome` and each `commentAfterEachTurn.outcome` (its `suggestNextPrompt.outcome`, when the call wrote no `commentAfterEachTurn`) carry the call's tokens, `cacheRead`, `cachePct` and `ms` (for `commentAfterEachTurn` and `suggestNextPrompt.outcome`, from the turn's end to the reply), and every model call writes one `call.cost` record (its tokens, and how many turns and characters its memory held and cut), which `npm run audit` in the repository totals. Below 40 columns the bubble is drawn above the character, and a long one is cut with `…`; `ambiguousCharacterWidth` (narrow or wide, default narrow) is for a terminal that draws East Asian ambiguous-width characters two columns wide. Your own characters are JSON files in the folder the `customCharactersDir` option names; the id `original` is reserved, and a file taking it is refused with an error naming it, in the personality tab's Yours group and in the bubble at each session start and `/buddy reload`.

## Pick a personality

`/buddy` opens the drawer; every act in it is a ctrl+x chord, their guide at its bottom-left: `ctrl+x  tab ask · t talk/personality · u use the idea · n next character · b previous character · p pet · x close`. ctrl+x b, ctrl+x x and ctrl+x tab work as they are; the other four need this in `~/.claude/keybindings.json` (`$CLAUDE_CONFIG_DIR/keybindings.json` when that is set), merged into the file if you have one: `{"bindings":[{"context":"Global","bindings":{"ctrl+x t":"pane:next","ctrl+x u":"pane:previous","ctrl+x n":"diff:back","ctrl+x p":"permission:toggleDebug"}}]}`. Its talk tab is the whole thread the buddy remembers, its personality tab a list with a live preview of the lit entry, in two groups: Shipped, the characters that come with it; Yours, first the companion Claude Code's removed `/buddy` hatched for your account (read from `~/.claude.json` or a backup of it, or with `CLAUDE_CONFIG_DIR` set from `$CLAUDE_CONFIG_DIR/.claude.json` and `$CLAUDE_CONFIG_DIR/backups/` instead; never written), listed as the native and the npm install rolled it, then your `customCharactersDir` files. ctrl+x n and ctrl+x b light the next or previous entry and switch to it at once, remembered across `/reload` and restarts; one that cannot be drawn is lit, its preview saying why, and never picked.

It requires function hooks: add `"env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" }` to `~/.claude/settings.json` (`$CLAUDE_CONFIG_DIR/settings.json` when that is set); without them a new session says `buddy is off: …`. Every option has a default, so a `userConfig options not yet set` notice after install can be ignored. It draws in the terminal and the desktop app. The full documentation and the character guide live in the repository: https://github.com/rezzminator/buddy
